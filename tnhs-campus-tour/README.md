# TNHS Campus Tour

Welcome to the TNHS Campus Tour project! This project provides a virtual tour of Talipan National High School, showcasing its facilities, academic environment, and community.

## Project Structure

```
tnhs-campus-tour
├── index.html          # Main HTML file for the campus tour website
├── assets              # Directory for assets
│   ├── css            # Contains styles for the website
│   │   └── index.css  # Stylesheet for layout, colors, and responsive design
│   ├── js             # Contains JavaScript files for interactivity
│   │   └── index.js   # JavaScript for handling testimonials and animations
│   ├── videos         # Directory for video files used in the website
│   └── images         # Directory for image files used throughout the website
├── components          # Directory for reusable HTML components
│   ├── navbar.html     # HTML structure for the navigation bar
│   └── footer.html     # HTML structure for the footer
├── data                # Directory for data files
│   └── testimonials.json # JSON file containing testimonial data
├── .gitignore          # Specifies files and directories to be ignored by Git
├── package.json        # Configuration file for npm, listing dependencies and scripts
└── README.md           # Documentation for the project
```

## Features

- **Virtual Campus Tour**: Explore the campus through an interactive online experience.
- **Responsive Design**: The website is designed to be accessible on various devices.
- **Dynamic Testimonials**: Real feedback from students is displayed in a carousel format.
- **Embedded Campus Building Tree**: An interactive iframe showcasing the campus layout.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd tnhs-campus-tour
   ```
3. Install dependencies (if any):
   ```
   npm install
   ```
4. Open `index.html` in your web browser to view the campus tour.
